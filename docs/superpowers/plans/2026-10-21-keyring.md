# Credentials in the System Keyring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No key in plain text under `~/.aria`: fixed keys become `!aria secret …` commands backed by the keyring, and
the files Pi rewrites (`auth.json`, `mcp-auth.json`) are sealed in the keyring with a live copy outside `~/.aria`.

**Architecture:** `aria-core/src/keyring.rs` (one `Backend` trait: macOS `security`, Linux `secret-tool`, memory) and
`aria-core/src/vault.rs` (live folder, open/sync/close, migration, command strings). `AriaPaths` carries an optional
`Vault`; with it, `auth()`/`mcp_auth()` point at the live copies and the writers store keys in the keyring. The dock
opens the vault at start, syncs it every second, closes it on quit.

**Tech Stack:** Rust (aria-core, aria), `base64` 0.22 and `sha2` 0.10 (already dependencies), `/usr/bin/security`
(macOS), `secret-tool` from libsecret (Linux), POSIX sh for the installer.

**Spec:** `docs/superpowers/specs/2026-10-21-keyring-design.md`

## Global Constraints

- Service `aria` for the default home (`$HOME/.aria`); `aria:<root>` for any other `ARIA_HOME`.
- Accounts: `key:<provider>`, `mcp:<server>:header:<name>`, `mcp:<server>:env:<name>`, `file:auth.json`, `file:mcp-auth.json`.
- Values stored base64 (standard alphabet, padded) of their UTF-8 bytes.
- macOS writes only via `security -i` with the command on stdin, with `-U -T /usr/bin/security`; never the secret in argv; exit 44 = missing.
- Linux: `secret-tool store --label <label> service <service> account <account>` (secret on stdin), `lookup`, `clear`.
- File commands: `!'<exe>' secret --home '<root>' '<account>'` (POSIX single-quote escaping), `<exe>` from `control::binary_path(current_exe())`.
- Live folder: Linux `$XDG_RUNTIME_DIR/aria-secrets-<id>`, macOS `<confstr(_CS_DARWIN_USER_TEMP_DIR)>/aria-secrets-<id>`; `<id>` = first 12 hex chars of sha256(root); folder 0700, files 0600.
- Secret-looking `mcp.json` values: every `headers` value of a server with `url`; `env` values whose name contains `KEY`, `TOKEN`, `SECRET`, `PASSWORD` or `AUTH` (case-insensitive); never a value already starting with `!` or containing `${`.
- No test may touch the real keyring except `#[ignore]` live tests with service `aria-test-<pid>` that delete what they make.
- Never delete a plain file whose content the keyring did not return byte-for-byte.
- Code, names, comments, docs and commits in English; match the surrounding style (comment density, naming).

## Review Focus

1. A key with a single quote, a space or a newline in it (or a root path with `'`): the command must still round-trip — test in Task 3 (`shell_quote`) and Task 1 (values with newlines and quotes).
2. The keyring returns a different value than was stored (or errors mid-migration): files stay untouched — Task 4 tests with a lying backend.
3. A crash between Pi rewriting the live `mcp-auth.json` and the next sync: the next open must keep the live copy, not the stale keyring one — Task 3 test `open_after_a_crash_keeps_the_newer_live_copy`.
4. `aria secret` on a missing account or a locked keyring prints nothing on stdout and exits 1 — Task 6 test.
5. A dock started with `credentials.keyring: false` or no keyring available behaves exactly as today (plain files, no live folder, no commands written) — Task 6 test `a_dock_without_the_keyring_keeps_plain_files`.

**Interfaces:**
- Consumes: Task 1 `Backend`, `KeyringError`.
- Produces:
  - `#[derive(Clone, Debug)] pub struct Vault { pub keyring: Arc<dyn Backend>, pub live: PathBuf, pub exe: PathBuf }`
  - `AriaPaths { root, vault: Option<Vault> }`; `AriaPaths::new(root)` and `from_env()` set `vault: None`. `auth()` → `vault.live.join("auth.json")` when set, else `root.join("auth.json")`; same for `mcp_auth()`. Every existing `AriaPaths { root }` literal becomes `AriaPaths::new(root)`.

  - `pub fn shell_quote(s: &str) -> String` (`'` → `'\''`, wrapped in `'…'`).

  - `#[derive(Debug, thiserror::Error)] pub enum VaultError { Keyring(#[from] KeyringError), Io(#[from] std::io::Error), Mismatch(String) }`.
