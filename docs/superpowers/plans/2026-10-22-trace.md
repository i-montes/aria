# Live trace (`/debug`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/debug true` in a tab opens a live waterfall of the current turn (LLM calls, tools, subagents with time,
tokens and cost) to the left of the chat.

**Architecture:** The dock builds the trace (`crates/aria/src/trace.rs`, pure) from the chat's Pi events and the
subagent watch's spans, and sends the whole tree to the page as `chatTrace` (≤ 4/s). The page draws it with a pure
part (`ui/chat/parts/trace.js`) in a panel left of the 470 px column; the surface widens on `wide`.

**Tech Stack:** Rust (serde_json), plain JS modules + CSS (bun test), Pi extension TypeScript (bun test), headless
Chrome sandbox (`tools/ui-sandbox`).

**Spec:** `docs/superpowers/specs/2026-10-22-trace-design.md`

## Global Constraints

- Everything in English (code, names, docs, commits); page texts in English and Spanish (`TEXTS.en` / `TEXTS.es`).
- `/debug` is per tab, in memory only; off after a restart; nothing written to disk.
- Times in the tree are ms from the turn's start; a running span has no `end`; cost and tokens are each span's own.
- At most 500 spans per trace (`dropped` counts the rest); previews cut at 2,000 characters; image data stripped.
- `chatTrace` at most every 250 ms while something changed, plus one on settle.
- Surface: 700 px normally, 1,060 px wide; trace panel 560 px + 16 px gap left of the 470 px column.
- Colours: agents grey, LLM violet, tools teal, failed red. Axis steps 10 s, 20 s, 30 s, 1 min, 2 min, 5 min, 10 min, 20 min, 30 min, 1 h.
- Both platforms keep working: GTK code is type-checked with `sh tools/check-macos.sh`'s Linux counterpart where possible; say what was not run.
- Conventional commits; never a co-author line.

## Review Focus

1. A turn with no `message_start` for the user (a scheduled or steered prompt) → the root's `input` stays empty, nothing breaks. (Task 1 test `a_turn_without_a_user_message_has_no_input`.)
2. `/debug true` turned on mid-turn → the trace starts at the next `agent_start`; the panel shows the empty state, not a half tree. (Task 4 test `on_mid_turn_waits_for_the_next_turn`.)
3. A tab closed or Pi restarted while traced → no `chatTrace` after the close; a restart mid-turn fails the root. (Task 4 test `a_restart_mid_turn_fails_the_root`.)
4. Switching to a tab without a trace while wide → `wide {on:false}` is sent and the panel hides. (Task 7 sandbox check.)
5. A provider that reports no cost (`usage.cost.total` 0 or missing) → the header shows "—", not "$0". (Task 6 test `no_cost_reads_as_a_dash`.)

### Task 1: The trace builder

**Files:**
- Create: `crates/aria/src/trace.rs`
- Modify: `crates/aria/src/main.rs` (add `mod trace;`)

**Interfaces:**
- Produces:
  - `pub struct Trace` with `pub fn new(started_ms: i64) -> Trace`, `pub fn started_ms(&self) -> i64`,
    `pub fn feed(&mut self, event: &serde_json::Value, at_ms: i64) -> bool` (true when the tree changed),
    `pub fn settle(&mut self, failed: bool, at_ms: i64)`, `pub fn tree(&self, agents: &[TraceAgent], now_ms: i64) -> Value`.
  - `pub struct TraceAgent { pub id: u64, pub name: String, pub task: String, pub started_ms: i64, pub ended_ms: Option<i64>, pub failed: bool, pub call: Option<String>, pub spans: Vec<Value> }` — spans already shaped like trace spans but with **epoch** `start`/`end`; `tree` rebases them.
  - `pub const MAX_SPANS: usize = 500; pub const PREVIEW: usize = 2000;`
- Tree JSON: root `{id:"root", kind:"agent", name:"Aria", detail, status, start:0, end?, input, now, dropped, children}`; spans as the spec's example. Ids: `llm-<n>` (1-based per turn), `tool-<toolCallId>`, `compaction-<n>`, `agent-<id>`, inside an agent `agent-<id>-<span id>`.

- [ ] **Step 1: Write the failing tests** (in `trace.rs` `#[cfg(test)]`), each feeding JSON events with explicit `at_ms`:
  - `an_llm_call_spans_message_start_to_end_with_usage`: `message_start` assistant at 100, `message_end` at 900 with `model:"m"`, `usage{input:10,output:5,cacheRead:3,reasoning:2,cost:{total:0.01}}`, text content "ok" → child `llm-1` `{start:100,end:900,detail:"m",tokensIn:10,tokensOut:5,cacheRead:3,reasoning:2,cost:0.01,output:"ok",status:"done"}`.
  - `a_failed_or_aborted_message_fails_its_span`: `stopReason:"error"` with `errorMessage:"boom"` → `failed`, `error:"boom"`; `"aborted"` → `failed`, `error:"stopped"`.
  - `a_tool_spans_its_execution_by_call_id`: start `{toolCallId:"c1", toolName:"bash", args:{command:"ls -la"}}` at 200, end `isError:false, result.content[text "out"]` at 500 → `tool-c1 {name:"bash", detail:"ls -la", input:<args JSON, ≤2000>, output:"out", start:200, end:500}`; `isError:true` → `failed`, `error` = the output text.
  - `the_users_message_is_the_roots_input`: `message_start` role user content `[{type:"text",text:"launch it"}]` → root `input:"launch it"`.
  - `a_turn_without_a_user_message_has_no_input`: only an assistant message → root `input` is `""`, tree valid.
  - `compaction_is_a_span`: `compaction_start` / `compaction_end` → `compaction-1`, kind `tool`, name `compaction`.
  - `settle_ends_the_root`: `settle(false, 1200)` → root `status:"done", end:1200`; `settle(true, …)` → `failed`; running spans left open are ended at the settle time and failed.
  - `previews_are_cut`: an output of 5,000 chars → 2,000 chars (char boundary safe).
  - `over_500_spans_the_oldest_finished_go`: 600 finished tool spans → 500 children, `dropped:100`, the newest kept; a running span is never dropped.
  - `agents_go_under_their_call_or_the_root`: a `TraceAgent{call:Some("c1")}` lands in `tool-c1.children`; `call:None` or an unknown call → root children; an agent with `started_ms` before `started_ms()` is left out; its spans' epoch times are rebased; `ended_ms:None` → `running`.
  - `the_detail_of_a_tool_is_its_target`: `read {path:"/a/b"}` → `/a/b`; `web_search {query:"q"}` → `q`; unknown → first string arg, one line, ≤ 80 chars.

### Task 4: The chat traces a tab on request

**Files:**
- Modify: `crates/aria-core/src/bridge.rs` (messages + serde tests)
- Modify: `crates/aria/src/chat.rs` (Inner fields, `pump`, `handle`, emit), `crates/aria/src/handlers.rs` (`wide` arm)
- Modify: `crates/aria-engine/tests/fake_pi.sh` (a `TRACE` prompt)

**Interfaces:**
- Produces:
  - `PageMessage::TraceSet { on: bool }` (`"traceSet"`, arrives wrapped in `session`), `PageMessage::Wide { on: bool }` (`"wide"`, top level, handled by the docks; a no-op arm in `handlers::handle`, not in `is_chat`).
  - `DockMessage::ChatTrace { trace: Value }` (`"chatTrace"`, sent through the chat's session emit; `trace` is the tree or `null`).
  - `Inner` gains `trace_on: bool`, `trace: Option<Trace>`, `trace_sent: Option<Instant>`, `trace_pending: bool`.
  - `fn trace_changed(&self)`: emits now if ≥ 250 ms since `trace_sent`, else sets `trace_pending` and spawns one thread that sleeps the rest and emits (only one at a time). Emit = `DockMessage::ChatTrace { trace: trace.tree(&watch.trace_agents(), now) }`.
- Behaviour: with `trace_on`, `agent_start` → `Trace::new(now)` (+ changed); every other event → `feed` (changed when it returns true); `agent_settled` → `settle(last_failed || aborted, now)` and an immediate emit; the watch's `on_change` also calls `trace_changed` when a trace exists; `Exited` while running → `settle(true, now)` + emit. `TraceSet{on:true}` → flag on, answer at once with the current tree or `null`; `on:false` → flag off, `trace = None`, send `null`. A closed chat sends nothing more.
- `fake_pi.sh`: a prompt containing `TRACE` prints, after `agent_start`: `message_start` user, `message_start` assistant, `message_end` assistant with `model` and `usage` (`cost.total` 0.01), `tool_execution_start` (`toolCallId:"c1"`, `toolName:"bash"`, `args:{command:"ls"}`), `tool_execution_end` (`c1`), then the usual settle.
