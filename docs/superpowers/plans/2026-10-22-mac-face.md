# Aria's Face Beside the Notch (macOS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On macOS, Aria's face plays what Aria is doing in a black wing beside the notch, drawn with Core Animation.

**Architecture:** A pure motion engine (`face_motion.rs`, a port of `Face.qml`'s logic) produces a `Frame` per tick; a
macOS layer tree (`dock/face_layers.rs`) paints it; a wing panel (`dock/face_wing.rs`) places it beside the notch and
toggles the dock on click. The dock's existing 16 ms main-thread tick (`ui::every(16, …)` in `main.rs`) drives it;
`face.rs` hands it each new face through `on_change`.

**Tech Stack:** Rust, objc2 0.6 / objc2-app-kit 0.3, new `objc2-quartz-core` 0.3 and `objc2-core-graphics` 0.3.

**Spec:** `docs/superpowers/specs/2026-10-22-mac-face-design.md`

## Global Constraints

- Constants (springs, timers, sizes, colours, SVG paths) copied from `install/omarchy/aria.face/Face.qml` as they are.
- Faces: `idle thinking reading editing working delegating asking scheduled done error sleeping`; unknown word → idle.
- Wing: 38 pt wide; notch height (`safeAreaInsets.top`) beside the notch, menu-bar height without; bottom corner radius 10 pt; face 22 pt.
- Level above the menu bar; never key; every Space; beside full-screen apps.
- Frames only while the wing is visible (occlusion state); `dt` capped at 0.05 s.
- `ARIA_FACE=<word>` forces a face (debugging only).
- Linux unchanged; `face_motion.rs` compiles and tests on both.
- English everywhere; conventional commits; no co-author lines.

## Review Focus

1. A face change that arrives mid-blink or twice in 130 ms → the last word wins, once. (Task 1 `the_last_word_wins`.)
2. A long gap (sleep, lock) → one capped step, values stay finite. (Task 1 `a_long_gap_is_one_capped_step`.)
3. Screens rearranged (external main screen, lid closed) → the wing moves to the notched screen or the pill. (Task 3 cases.)
4. The face callback fires off the main thread → no AppKit call off main. (Task 2 design: a shared slot read on the tick.)
5. Ten minutes of each look → no NaN, no runaway values. (Task 1 `every_look_stays_finite`.)
